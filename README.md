# 🩺 AppointYourDoc

A modern, full-stack healthcare appointment platform that enables patients to discover verified doctors, check real-time availability, and book appointments seamlessly — built with performance, scalability, and user experience at its core.

---

## ✨ Overview

**AppointYourDoc** is a production-ready doctor appointment booking system designed to remove friction from healthcare access.  
Patients can easily find doctors, view available slots, and manage appointments, while doctors can control availability and track bookings — all within a clean, fast, and intuitive interface.

The platform focuses on:
- Reliability
- Transparency
- Real-time interactions
- A modern, consistent UI experience

---

## 🚀 Key Features

### 👩‍⚕️ For Patients
- Browse verified doctors by specialization and city
- View real-time doctor availability
- Book appointments instantly
- Track upcoming and past appointments
- Clean, distraction-free interface

### 🧑‍⚕️ For Doctors
- Create and manage availability slots
- View patient appointments in real time
- Role-based dashboard experience
- Simple, efficient workflow

### 🔐 Authentication & Security
- JWT-based authentication
- Role-based access control (Patient / Doctor)
- Secure API communication
- Protected routes

## 🔄 Application Flow

1. User registers as **Patient** or **Doctor**
2. JWT token is issued on login
3. Role-based navigation is enabled
4. Patients browse doctors and book appointments
5. Doctors manage availability and appointments
6. Data updates in real time through API calls
